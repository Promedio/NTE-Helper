这是一个非常底层但很有意思的需求。键盘的自动重复（Auto-Repeat）通常由两个参数控制：**延迟（Delay）**（第一次按下到第一次重复的时间）和**速度（Speed/Rate）**（后续重复的频率）。

由于你没有指定操作系统和编程语言，我为你整理了三大主流平台（Windows、macOS、Linux）获取该系统参数的核心底层 API 和方法。

### 1. Windows 平台 (Win32 API)

在 Windows 中，你可以使用 `SystemParametersInfo` 函数来获取这个系统级设置。

- **API:** `SystemParametersInfoW`
- **控制宏:** `SPI_GETKEYBOARDDELAY`

#### C++ 示例代码

```c++
#include <windows.h>
#include <iostream>

int main() {
    UINT delay = 0;
    // 获取键盘重复延迟
    if (SystemParametersInfo(SPI_GETKEYBOARDDELAY, 0, &delay, 0)) {
        std::cout << "Windows 键盘延迟索引值 (0-3): " << delay << std::endl;
        
        // Windows 的延迟值是一个 0 到 3 的索引：
        // 0 约等于 250ms
        // 1 约等于 500ms
        // 2 约等于 750ms
        // 3 约等于 1000ms (1秒)
        int approx_ms = (delay + 1) * 250;
        std::cout << "大约对应的毫秒数: " << approx_ms << "ms" << std::endl;
    } else {
        std::cerr << "获取失败，错误码: " << GetLastError() << std::endl;
    }
    return 0;
}
```

> **顺带一提：** 如果你还需要获取重复速度，可以使用 `SPI_GETKEYBOARDSPEED`，它会返回一个 0（约 2 次/秒）到 31（约 30 次/秒）的值。

### 2. macOS 平台

macOS 没有直接像 Windows 那样爽快的 C 语言全局 API，它的键盘重复行为记录在全局首选项（Global Preferences）中。

#### 命令行/读取配置方式

在底层，你可以通过读取 `NSUserDefaults` 或者执行 shell 命令来获取：

```bash
defaults read -g InitialKeyRepeat
```

- **返回值含义：** macOS 返回的是“滴答数”（Ticks），1 个 Tick 约等于 15 毫秒（ms）。
- 例如：返回 `15` 意味着延迟大约是 $15 \times 15 = 225\text{ms}$。系统滑块最快的配置通常是 `15`（225ms），最慢可能到 `120`（1800ms）。

#### Swift / Objective-C 代码

如果是在 macOS 应用内部，可以通过 `UserDefaults` 读取：

```swift
import Foundation

let defaults = UserDefaults.standard
// 注意：如果用户从未修改过默认值，这里可能返回 0，需要处理默认缺省值（通常是 35 或 68）
let initialRepeat = defaults.integer(forKey: "InitialKeyRepeat")
print("macOS 键盘延迟 (Ticks): \(initialRepeat)")
```

### 3. Linux 平台 (X11 / Wayland)

在 Linux 下，取决于你使用的是 X11 还是 Wayland 桌面服务器。

#### X11 环境 (常见)

你可以使用 `X11/Xlib.h` 中的 `XGetKeyboardControl` 函数。

```c
#include <X11/Xlib.h>
#include <stdio.h>

int main() {
    Display *display = XOpenDisplay(NULL);
    if (display == NULL) return 1;

    XKeyboardState state;
    XGetKeyboardControl(display, &state);

    // 注意：X11 的 XKeyboardState 原生可能只暴露了 auto_repeats 的位掩码
    // 通常需要通过 Xkb 扩展来获取更精准的毫秒级延迟：
    // XkbGetAutoRepeatRate(display, XkbUseCoreKbd, &timeout, &interval);
    
    XCloseDisplay(display);
    return 0;
}
```

- **更简单的做法（Shell 解析）：** 很多 Linux 开发者会直接在后台调用 `xset q` 并用正则匹配 `delay` 和 `rate` 行。它的返回值直接就是毫秒数（比如 `delay: 250  rate: 30`）。
